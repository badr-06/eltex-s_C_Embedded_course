## Взлом программы
### Статья про Переполнение буфера и перезапись адреса возврата. Метод эксплутации.

**иммеется исходный код в файле main.c**

![main.c](./images/Снимок%20экрана%20от%202026-02-02%2011-48-45.png)

нужно ввести неправильный пароль и вывести в консоль *Access granted!*

Компилируем программу с использованием флагов *"-fno-stack-protector -no-pie -g"*

> **gcc -fno-stack-protector -no-pie -g main.c**

Затем запускаем программу **gdb ./a.out**

![запуск программы](./images/Снимок%20экрана%20от%202026-01-31%2015-26-37.png)

Теперь нам нужно узнать адрес 17 строки, чтобы подставить этот адрес при возврате из функции IsPassOk
С помощью команды disas(disassemble) выводим ассемблерный код текущей функции, и запоминаем адрес 17 строки

![ассемблерный код функции main()](./images/Снимок%20экрана%20от%202026-01-31%2015-29-51.png)

![адрес 17 сроки](./images/Снимок%20экрана%20от%202026-01-31%2015-29-51.2.png)

Cтавим точку остнова в main *b main*, затем идем до вызова функции с помощью команды *ni* и заходим в фуникцию *si*

![ассемблерный код функции IsPassOk()](./images/Снимок%20экрана%20от%202026-02-02%2015-31-31.png)

Закрываем отладку, создаем файл *cin.txt* записывая туда адрес который мы запомнили с помощью команды *echo*

<u>важный момент
В 64 разрядной системе в основном адрес возврата из функции находится за стеком, можно проверить командой </u> 

> x /gx $rbp + 8

![адрес возврата](./images/Снимок%20экрана%20от%202026-02-02%2014-56-17.png)

В функции main адрес *0x00000000004011b6* находится после вызова функции IsPassOk, это и есть адрес возврата из функции, и чтобы его поменять, нам нужно зпонить все 12 байт **char Pass[12]** и затем заполнить 8 байт регистра сохраненного rbp, и за ним находится наш адрес возврата из функции.

с помощью команды создаем файл *cin*
> **echo -ne "AAAABBBBCCCCDDDDDDDD\xe2\x11\x40\x00\x00\x00\x00\x00" > cin**

Теперь заново запускаем отладчик, ставим точку остнова в main, затем идем до вызова функции IsPassOk и заходим в фуникцию и проверяем адрес возврата 

![x /2gx $rbp в функции IsPassOk()](./images/Снимок%20экрана%20от%202026-02-04%2010-15-02.png)

x /2gx - означает показать в 16-ом виде 2 блока по 8 байт. Можно также исползовать x /gx $rbp + 8 чтобы показовало только 8 байт адреса возврата 

затем идеи до инструкции вызова gets(), проходим её и опять проверяем адрес возврата. 

![x /2gx $rbp в функции IsPassOk()](./images/Снимок%20экрана%20от%202026-02-04%2010-15-36.png)


И видим что первые 8 байт заполнены числами 44 в 16-ом виде в десятичномм ввиде будет 68 (т.е. 4 * 16^0 + 4 * 16^1 = 68) а 68 - если мы посмотрим по ascii таблице это буква D, то есть то что мы записывали в файл, а второй блок в выводе это адрес 17 строки в main() который мы также записали в файл, сверьте с верхним скриншотом где мы выводили ассемблерный вид функции main().

Теперь мы просто идем до конца инструкций нашей функции. Чтобы перейти на адрес возврата.

![вызвалась 17 строка функции main()](./images/Снимок%20экрана%20от%202026-02-04%2010-16-13.png)

и теперь мы видим как вызвалась 17 строка фукнции main() которая вызывает функцию printf для вывода *Access granted!*. И на этом все, программа завершается.

![завершение программы](./images/Снимок%20экрана%20от%202026-02-04%2010-16-24.png)
